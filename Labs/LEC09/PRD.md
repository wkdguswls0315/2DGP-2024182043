# 소닉 스프라이트 애니메이션 뷰어 PRD



커밋할 때 메시지는 반드시 한글로 한다.

## 1. 문서 목적

이 문서는 `Labs/LEC09`의 소닉 스프라이트 시트를 이용하는 애니메이션 뷰어의 요구사항과 구현 기준을 정의한다. 구현은 Python과 Pico2D를 사용하며, 스프라이트 시트에 포함된 애니메이션을 순서대로 자동 재생한다.

## 2. 제품 개요

| 항목      | 내용                            |
| --------- | ------------------------------- |
| 제품명    | 소닉 스프라이트 애니메이션 뷰어 |
| 실행 환경 | Python, Pico2D                  |
| 소스 파일 | `sonic_animation_viewer.py`   |
| 입력 에셋 | `sonic-sprite.png`            |
| 화면 크기 | 1200 × 800 픽셀 기준           |

초안에 적힌 에셋 이름 `sonic.sprite.png`는 LEC09 폴더의 실제 파일명과 일치하지 않는다. 구현에서는 저장소에 있는 `sonic-sprite.png`를 사용한다.

## 3. 목표와 범위

### 목표

- 스프라이트 시트에 포함된 각 애니메이션을 빠짐없이 재생한다.
- 동작 사이의 전환과 대기 시간을 일정하게 유지한다.
- 스프라이트를 화면에서 식별하기 좋은 크기로 확대해 표시한다.
- 전체 동작 순회를 마친 뒤에도 재생을 계속 반복한다.

### 범위

- 단일 Python 파일에서 애니메이션 뷰어를 구현한다.
- 각 동작의 프레임 영역, 프레임 수 및 재생 속도를 코드에서 관리한다.
- Pico2D 창에서 프레임을 자르고 화면에 그린다.

### 제외 범위

- 스프라이트 시트나 이미지 에셋 자체의 편집
- 외부 애니메이션 파일 형식 또는 별도 에셋 로더 지원
- 사용자 인터페이스를 통한 애니메이션 편집 및 내보내기

## 4. 기능 요구사항

### FR-1. 애니메이션 목록 구성

- 스프라이트 시트의 각 애니메이션 동작과 프레임을 식별할 수 있어야 한다.
- 모든 동작을 재생 순서대로 목록화하고, 각 동작의 프레임 좌표와 크기를 정확히 설정해야 한다.
- 프레임이 가로 한 줄에만 배치되지 않은 동작도 시트의 실제 배치에 맞게 정의해야 한다.

### FR-2. 동작 재생

- 현재 동작의 프레임을 순서대로 표시한다.
- 현재 동작의 애니메이션을 총 5회 반복한 다음 해당 동작의 재생을 마친다.
- 한 동작을 마치면 1초 동안 대기한 후 다음 동작으로 넘어간다.
- 목록의 마지막 동작까지 재생한 후 첫 동작으로 돌아가 같은 순서를 무한 반복한다.

### FR-3. 화면 표시

- Pico2D 창을 열고 매 프레임 화면을 갱신한다.
- 원본 이미지에서 현재 프레임 영역을 잘라 그린다.
- 원본 프레임 크기에 비례해 확대하여 표시하고, 종횡비를 유지한다.
- 확대된 프레임이 창 안에서 잘 보이도록 화면의 표시 위치와 크기를 정한다.

### FR-4. 종료 처리

- 운영체제의 창 닫기 이벤트를 처리하고, 재생 루프를 종료한 뒤 Pico2D 창을 닫는다.

## 5. 구현 설계 기준

- 모든 구현 코드는 `sonic_animation_viewer.py` 한 파일에 둔다.
- 애니메이션별 메타데이터(프레임 수, 시작 좌표, 프레임 크기, 프레임 간격, 재생 간격)는 일관된 자료 구조로 관리한다.
- 프레임 진행, 동작 반복 횟수, 동작 간 대기 및 전체 순환 상태를 구분해 관리한다.
- 각 프레임의 클리핑 좌표는 PNG의 원점 방향과 Pico2D의 클리핑 좌표 규약에 맞춰 검증한다.
- 이미지 경로는 실행 작업 디렉터리에 의존하지 않도록 스크립트 위치를 기준으로 결정한다.

## 6. 비기능 요구사항

- 화면 갱신과 애니메이션 시간 측정이 분리되어야 하며, 일시적인 프레임 지연에도 애니메이션 상태가 무한히 밀리지 않아야 한다.
- 반복 재생 중 창 종료 이벤트에 응답할 수 있어야 한다.
- 프로젝트에 이미 포함된 Pico2D와 PNG 에셋 외에 불필요한 런타임 의존성을 추가하지 않는다.

## 7. 완료 기준

- [ ] `Labs/LEC09/sonic_animation_viewer.py`를 실행하면 `sonic-sprite.png`를 불러온다.
- [ ] 스프라이트 시트에 확인된 모든 애니메이션 동작이 정의된 순서대로 표시된다.
- [ ] 각 동작은 정확히 5회 애니메이션을 반복한다.
- [ ] 각 동작의 다섯 번째 재생이 끝난 뒤 다음 동작 시작까지 1초 대기한다.
- [ ] 마지막 동작 뒤 첫 동작부터 전체 순서가 다시 시작된다.
- [ ] 화면 크기가 1200 × 800 픽셀이고, 프레임이 식별 가능한 크기로 확대되며 이미지 비율이 유지된다.
- [ ] 창 닫기 이벤트로 프로그램을 정상 종료할 수 있다.

## 8. 단계별 개발 및 커밋 절차

초안은 모든 코드를 한 번에 작성하지 않고 단계적으로 구현하며 20회 이상의 커밋을 남기도록 요구한다. 각 커밋은 동작을 검토할 수 있는 작은 단위로 나누고, 기능 추가 또는 검증 가능한 개선 내용을 담는다. 커밋 수를 채우기 위한 의미 없는 변경은 하지 않는다.

권장 개발 순서는 다음과 같다.

1. 에셋과 좌표계를 확인하고 애니메이션 프레임 목록을 작성한다.
2. Pico2D 창과 스프라이트 시트 로딩을 구성한다.
3. 단일 프레임 클리핑 및 확대 출력을 확인한다.
4. 동작별 프레임 순차 재생을 구현한다.
5. 동작별 5회 반복과 반복 상태 초기화를 구현한다.
6. 동작 전환 및 1초 대기를 구현한다.
7. 전체 동작 목록의 무한 순환을 구현한다.
8. 종료 이벤트, 시간 처리 및 완료 기준을 검증한다.
